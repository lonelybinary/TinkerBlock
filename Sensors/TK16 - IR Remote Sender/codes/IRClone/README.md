# IRClone — Copy & Replay an IR Remote (ESP32-S3)

Turns the ESP32-S3 into a **learning universal remote**. Point an original
remote at the IR receiver, "copy" a button into a memory slot, then "send" that
slot through the IR sender to reproduce the exact same signal.

It clones both well-known protocols (NEC, Samsung, Sony, RC5, …) by storing the
decoded address/command, and unknown/long signals (many air-conditioner codes)
by storing the raw timing and replaying it. Up to **5** buttons at once.

## Hardware

This uses **two** modules — an IR receiver to copy and an IR sender to replay:

| Module | Signal → ESP32-S3 | Power |
| ------ | ----------------- | ----- |
| TK15 IR **Receiver** | GPIO 3 | VCC → 3.3V, GND → GND |
| TK16 IR **Sender**   | GPIO 4 | VCC → 3.3V, GND → GND |

Both pin numbers are `#define`s at the top of the sketch.

## Library

- **IRremote** by Armin Joachimsmeyer (v4.x or newer) —
  *Tools → Manage Libraries → search "IRremote"*.

## How to use

1. Install the IRremote library, select your ESP32-S3 board and port, upload.
2. Open **Serial Monitor** at **115200 baud**.
3. Use the menu:

```
============== IR CLONE ==============
  c <n>   Copy : capture next remote press into slot n
  s <n>   Send : replay slot n through the IR sender
  l       List : show all stored slots
  e <n>   Erase: clear slot n
  h       Help : show this menu
  n = 1..5
```

**Typical flow**

- `c 1` → the sketch waits; point the original remote at the receiver and press
  a button. It stores the code in slot 1 and prints what it captured.
- `s 1` → transmits that code from the TK16 sender (aim it at the target device).
- `l` → lists all stored slots. `e 1` → erases slot 1.

Example capture:

```
Copied into slot 1
  Slot 1: NEC  Address=0x4 Command=0x8 Bits=32
```

To cancel a capture while it is waiting, type any letter (e.g. `x`) and Enter.

## How the cloning works

- **Known protocol** → decoded into address/command and replayed with
  `IrSender.write()` — compact and exact.
- **Unknown / long signal** → falls back to **raw timing capture** and replays
  with `IrSender.sendRaw()` at 38 kHz, so it clones remotes IRremote can't decode.
- Held-button **repeats are ignored** during capture (it grabs the clean initial
  frame).

`RAW_BUFFER_LENGTH` is set to 750 (before the IRremote include) to fit long codes.
If a captured signal is longer than that, you'll get an overflow message — raise
the value and re-upload.

## Notes & troubleshooting

- **Serial line ending:** any setting works ("Newline", "Both NL & CR", …). The
  sketch drains the trailing line-ending so it isn't mistaken for a cancel key.
- **Receiver is paused during transmit.** On ESP32 the IR carrier is generated by
  the hardware PWM (LEDC); leaving the 50 µs receive interrupt running during a
  send corrupts the FreeRTOS scheduler and crashes the board. The sketch calls
  `IrReceiver.stop()` before sending and `IrReceiver.start()` after — keep this if
  you modify `sendSlot()`.
- **Nothing captured?** Get closer, aim at the receiver, use fresh batteries, and
  avoid strong sunlight / fluorescent lighting.
- **Send has no effect?** Aim the TK16 LED directly at the device's IR window from
  close range; IR is directional and short-range at low power.

## Editing

- Change `IR_RECEIVE_PIN`, `IR_SEND_PIN`, `NUM_SLOTS`, `RAW_BUFFER_LENGTH` at the
  top of the sketch.
- Menu commands are handled in `handleCommand()`; capture/replay logic lives in
  `captureToSlot()`, `storeToSlot()`, and `sendSlot()`.
